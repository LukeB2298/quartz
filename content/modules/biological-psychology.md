# Biological Psychology

Biological psychology (also called biopsychology or behavioral neuroscience) studies the physiological, genetic, and developmental mechanisms underlying behavior and mental processes.

## Neuroanatomy

### Major brain structures
| Structure | Function |
|---|---|
| Cerebral cortex | Higher cognition, planning, decision-making |
| Hippocampus | Memory formation and spatial navigation |
| Amygdala | Emotional processing, especially fear |
| Hypothalamus | Homeostasis, hunger, thirst, temperature |
| Thalamus | Relay station for sensory information |
| Cerebellum | Motor coordination and balance |
| Brainstem | Autonomic functions (breathing, heart rate) |

### The lobes of the cerebral cortex
- **Frontal lobe** — executive function, motor cortex, Broca's area
- **Parietal lobe** — somatosensory processing, spatial attention
- **Temporal lobe** — auditory processing, Wernicke's area, memory
- **Occipital lobe** — visual processing

## Neurotransmitters

| Neurotransmitter | Key functions |
|---|---|
| Dopamine | Reward, motivation, motor control |
| Serotonin | Mood, appetite, sleep |
| Norepinephrine | Arousal, attention, stress response |
| GABA | Primary inhibitory neurotransmitter |
| Glutamate | Primary excitatory neurotransmitter |
| Acetylcholine | Memory, muscle activation, autonomic nervous system |

## Methods in biological psychology

- **EEG** — electroencephalography, measures electrical brain activity
- **fMRI** — functional magnetic resonance imaging, tracks blood flow
- **PET** — positron emission tomography, measures metabolic activity
- **Lesion studies** — examining behavior after brain damage
- **Optogenetics** — controlling neurons with light (animal studies)
- **TMS** — transcranial magnetic stimulation, temporarily disrupts brain activity

## The nervous system

- **Central nervous system** — brain and spinal cord
- **Peripheral nervous system**
  - Somatic nervous system — voluntary movement
  - Autonomic nervous system — involuntary functions
    - Sympathetic — fight or flight
    - Parasympathetic — rest and digest
