# Psychology Notes

Welcome to a curated collection of psychology coursework notes, designed for current and future bachelor's students. This site covers core modules from a BSc Psychology program, including cognitive psychology, social psychology, research methods, and more.

## How to use this site

- **Browse by module** using the file explorer on the left
- **Search** for specific topics using the search bar
- **Follow links** between concepts — each note connects to related ideas
- **Check the graph** on the right to see how topics relate

## Modules

- [[Cognitive Psychology]] — memory, attention, perception, language
- [[Social Psychology]] — group dynamics, attitudes, social cognition
- [[Research Methods]] — experimental design, statistics, SPSS
- [[Developmental Psychology]] — lifespan development, attachment theory
- [[Biological Psychology]] — neuroanatomy, neurotransmitters, brain imaging

## Getting started

If you're new to psychology, start with [[What is Psychology]] for an overview of the field, or jump straight into [[The Scientific Method in Psychology]] to understand how psychological research works.
