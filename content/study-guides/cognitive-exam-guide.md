# Cognitive Psychology Exam Guide

This guide summarizes the key topics to review for a cognitive psychology exam.

## Memory

### Multi-Store Model (Atkinson & Shiffrin, 1968)
- Three stores: sensory, short-term (7±2 items, ~30s), long-term (unlimited)
- Evidence: serial position curve (primacy = LTM, recency = STM)
- Criticism: oversimplified; [[Working Memory]] model is more nuanced

### Working Memory Model (Baddeley & Hitch, 1974)
- Central executive + phonological loop + visuospatial sketchpad + episodic buffer
- Evidence: dual-task studies, patient KF, word length effect
- Be able to draw the model diagram

### Levels of Processing (Craik & Lockhart, 1972)
- Deep (semantic) > shallow (structural) processing for recall
- Criticism: circular — "deep" is defined by better recall

### Ebbinghaus and forgetting
- Forgetting curve: rapid initial decline, then slower
- Spacing effect: distributed practice > massed practice

## Attention

- **Selective attention**: Broadbent (filter), Treisman (attenuation), Deutsch & Deutsch (late selection)
- **Dual-task performance**: automatic vs. controlled processing
- **Visual search**: feature vs. conjunction searches, feature integration theory

## Perception

- **Gestalt principles**: proximity, similarity, closure, continuity
- **Depth cues**: monocular (size, overlap, texture gradient) vs. binocular (retinal disparity, convergence)
- **Top-down vs. bottom-up**: how expectations influence perception

## Language

- **Broca's vs. Wernicke's aphasia**: non-fluent vs. fluent speech
- **Chomsky**: language acquisition device, universal grammar
- **Sapir-Whorf**: strong (deterministic) vs. weak (relativistic) linguistic relativity

## Common exam question types

1. **Describe and evaluate** a theory (e.g., "Describe and evaluate the Working Memory Model")
2. **Compare** theories (e.g., "Compare the Multi-Store and Working Memory models")
3. **Apply** concepts to a scenario
4. **Discuss** research evidence and methodological issues

## Key studies to memorize

| Study | What to remember |
|---|---|
| Ebbinghaus (1885) | Nonsense syllables, forgetting curve, method of savings |
| Miller (1956) | 7±2, chunking |
| Sperling (1960) | Iconic memory, partial report method |
| Peterson & Peterson (1959) | Duration of STM (~18s without rehearsal) |
| Baddeley (1966) | Acoustic vs. semantic confusion in STM vs. LTM |
