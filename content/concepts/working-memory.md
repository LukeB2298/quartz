# Working Memory

Working memory is a cognitive system for temporarily holding and manipulating information. It is a refinement of the short-term memory concept from the [[Multi-Store Model]].

## Baddeley & Hitch's model (1974)

The original model proposed three components:

### Central Executive
The attentional controller — supervises and coordinates the slave systems. It has limited capacity and is modality-free.

### Phonological Loop
Deals with verbal and acoustic information. Contains:
- **Phonological store** — holds auditory input for ~2 seconds
- **Articulatory rehearsal process** — subvocal repetition to maintain information

Evidence: [[Word Length Effect]] — longer words are harder to remember; articulatory suppression eliminates the effect.

### Visuospatial Sketchpad
Handles visual and spatial information. Allows mental imagery and spatial navigation.

## Extended model (2000)

Baddeley added the **episodic buffer** — a temporary store that integrates information from the phonological loop, visuospatial sketchpad, and long-term memory into coherent episodes.

## Key evidence

- **Dual-task paradigm** — visuospatial tasks interfere with visuospatial tracking but not verbal tasks (and vice versa)
- **Patient KF** — impaired verbal short-term memory but normal visual memory, supporting modularity
- **Neuroimaging** — different neural circuits for verbal vs. visuospatial working memory
